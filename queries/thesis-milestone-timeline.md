# 读研里程碑时间线（2026 级学硕）

依据 2026 版培养方案推导的执行视角时间线（学制 3 年；具体日期以学院通知为准）。^[raw/papers/peiyang-fangan-2026.extracted.txt]

| 阶段 | 事项 |
|---|---|
| Y1 秋 | 公共学位课（中特、英语、矩阵、数理逻辑）+ 专业学位课多为秋季开课；补修课程插入 |
| Y1 春 | 春季选修课、学术论文写作规范（必选）；课程学习基本结束（总则：课程学习约 1 年） |
| Y1 末–Y2 初 | **中期考核**（一般在课程结束后结合开题进行）→ 文献调研、选题、**开题** |
| Y2 | 实验研究、论文撰写；持续攒学术活动（≥8 次 + 1 次学术报告）、教学/社会实践、文献阅读考核 |
| Y2–Y3 | **学术成果产出**：期刊投稿（录用即可）或 发明专利公开 + 会议论文/竞赛（路径 B，见 [[academic-graduation-requirements]]）——期刊审稿周期长，应尽早投稿 |
| Y3 上 | 论文初稿、**预答辩**、修改 |
| Y3 下 | 评阅（盲审）、**答辩** → 学位评定委员会批准 → 硕士学位 + 毕业证 |

## 硬约束
- 在籍 ≤5 年；在校攻读 ≥2 年；学位论文形成 ≥1 年
- 全部课程学分 + 必修环节 4 学分达成后方可答辩
