# SCI论文写作工作流（从选题到成文）

问题：如何按 B 站《SCI论文写作》教程的路径完成一篇 SCI 论文？答案为综合全 20 集教程的执行流：**选题与目标 → 文献阅读 → 综述 → 引言 → 中间段 → 讨论与结论**，并以金字塔结构整体把关。^[raw/bilibili/SubBatch_2026-09-30-10-16-54_MD/【SCI论文写作】—【全20集】目前B站最完整的论文写作教程，包含所有干货内容！这还没人看，我不更了！ - P1【1论文的三段式结构】—【2024-04-03】-中文.md, raw/bilibili/SubBatch_2026-09-30-10-16-54_MD/【SCI论文写作】—【全20集】目前B站最完整的论文写作教程，包含所有干货内容！这还没人看，我不更了！ - P3【3研究选题的三种途径】—【2024-04-03】-中文.md, raw/bilibili/SubBatch_2026-09-30-10-16-54_MD/【SCI论文写作】—【全20集】目前B站最完整的论文写作教程，包含所有干货内容！这还没人看，我不更了！ - P18【18结果,讨论和结论的写作要点】—【2024-04-03】-中文.md]

## 阶段一：确立选题与研究目标
1. 从三条途径选题：填补研究空白 / 延伸现有研究 / 在不同情境下复制成功研究，检验是否满足好课题三准则（具体可行、开放可争议、激发创新）。
2. 以「大处着眼、小处着手」把 objective 挂在 goal 上。
3. 用 MECE 把核心矛盾分解、转化，量化关键变量、提假说。
4. 通过多表达文献检索（OR 求并 + AND 求交）细化目标；「检索—评估—细化」多次循环。
→ [[research-goal-formulation]]

## 阶段二：定义与描述目标
明确方向（指向 goal，两句话式定义 + 贡献）+ 明确边界（方法资源可行、结论可测、完成度可测量），用 determine / estimate 等完成意味动词，备齐 hypothesis 与 rationale。
→ [[research-goal-description]]

## 阶段三：文献阅读与整理
- 第一阶段泛读（由厚到薄）明确细化目标；第二阶段精读（由薄到厚）按目标收集论据；两阶段可循环。
- 守三不要（无选择精读/只读不写/来源不清），用三要（列表法、画圈法、自写摘要）整理资料。
- 境外数据库检索的合规通道见 [[offshore-network-access-policy]]。
→ [[literature-reading-method]]

## 阶段四：写引言（含文献综述）
- 按两段式模板：第一段从普遍 problem 到具体 question 确立研究机会，第二段以 goal/objective 提出解决方案填补空白。
- 文献综述守两个基本点（有所学：全新观；有所思：评+析），用 SCQA 讲有起伏的故事，落脚到自己的研究目标。
- 可参考三段式实例（普遍问题 → 具体问题 → 自己的目标）。
→ [[introduction-writing]]、[[literature-review-writing]]

## 阶段五：写中间段（目标/方法/结果）
按说明文把所做工作写清晰：方法可复制（结果与方法一一对应），结果客观、只述事实，两个一致（内容与方法、文字与图表）。
→ [[paper-three-segment-structure]]、[[discussion-and-conclusion-writing]]

## 阶段六：讨论与结论
- 讨论：按论点分段、按重要性排序；一段一理由，理由不需出处、证据必须引用；推进三种比较（预期/文献/长远目标）与四个方向（解释 → 延伸 → 局限 → 建议），语气适度、越具体越可信。
- 结论：总结讨论，突出亮点 + 指出局限与未来方向，缺一不可。
→ [[discussion-and-conclusion-writing]]

## 整体把关
用金字塔结构检查全文：结论在塔尖，一级小标题分承，段落与数据支撑；文字简练、内容层次详实（骨架实、血肉瘦）。
→ [[structured-thinking-pyramid]]

## 时间安排与外部约束
- 引言写作**不需要实验数据**，应尽早动笔（甚至早于实验），先写引言有助于理解目标、少走弯路。
- 投稿节奏与开题/中期节点对齐，见 [[thesis-milestone-timeline]]；论文等级与录用要求见 [[academic-graduation-requirements]]。
- 教程来源为单一 B 站 UP 主经验性内容（观点性，confidence medium），宜与本校开设的学术论文写作规范课程（见 [[cs-course-credits]]）及权威写作指南交叉验证。
