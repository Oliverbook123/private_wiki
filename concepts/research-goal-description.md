# 研究目标的定义与描述

把经过细化的具体研究目标清晰准确地写给读者，并用以指导研究活动，要把握两个关键点：**有明确的方向**、**有明确的边界**。^[raw/bilibili/SubBatch_2026-09-30-10-16-54_MD/【SCI论文写作】—【全20集】目前B站最完整的论文写作教程，包含所有干货内容！这还没人看，我不更了！ - P14【14如何定义和描述研究目标】—【2024-04-03】-中文.md]

## 明确方向：指向长远目标
- objective 为己独有，其意义对多数读者并不明显；需要指明它与普遍 goal 的关系，帮助读者理解其意义、与读者建立联系。
- 完整描述通常至少两句话：一句定义具体目标，另一句说明它对长远目标的贡献；两句的顺序与繁简可按强调重点与读者理解难度调整。
- 示例句式：「我们的具体研究目标是要确定变量 A 在某条件下是否对变量 B 有显著影响」「我们提出这一目标，是因为这将帮助我们更好地预测和管理变量 B」。

## 明确边界：包含什么、不包含什么
- 划定边界时须同时考虑对应的研究方法与可能得出的结论，自问两个问题：边界内是否**有有效方法、有足够资源、能在有限时间完成**？目标若达成，是否**能得出有意义的结论**？两问任一为否，则边界不当、目标不合格。
- 边界明确的副产物是**完成度可测量**：读者读结果即可判断目标是否达成。
- 常见误区是目标过于宽泛：边界过大则目标不可信；边界不清则传达出不自信。
- 动词选择：分析性研究常用有完成意味的 **determine**（to determine whether variable A is affected by variable B），定量描述性研究常用 **estimate**（to estimate the value of a certain variable using a certain method）。
- 忌用 **study / investigate**（无力量、不具体、无边界）与 **hope / seek / try**（字幕作 Hope sick try，sick 应为 seek；传达对所选目标的不自信）。

## 实例讲解（P15）
| 组 | 弱写法 | 强写法 |
|---|---|---|
| 1 | to **study** 家庭环境与语言能力对儿童入园适应的影响（无边界、无到达点，只看动作不看结果） | to **determine** 哪些关键因素对儿童入园适应度有较大影响（可测量；原来的研究变量是达成此目标的方法） |
| 2 | 评价一种雷达技术可否用于检测混凝土结构缺陷（验证假说，弱化了目标意义） | 发展一种无损检测技术检测混凝土结构缺陷（有里程碑意义、方向性更强、更连长远目标） |

- **goal → objective → hypothesis 链条**（第二、三组例）：长远目标（设计优化的混凝土结构）→ 具体目标（发展无损检测技术）→ 核心假说（某种雷达技术可精确检测缺陷）越来越具体；objective 在链条中间划出明确边界。hypothesis 是基于现有文献的大概率事件，假说成立则目标大概率可实现，故假说可视为选择该目标的**理由**之一。
- 对目标的双重支持（第四组例，转录存疑处保留原词）：长远目标为「制作基于自然肌理的有效抗癌药物」（「肌理」疑为「机理」之讹，转录存疑），具体目标为「确定 ROSETTING 物质对前列腺癌癌细胞转移的抑制机理和效果」（物质名 ROSETTING 为转录原样，疑有讹误），核心假说为「该物质可抑制某种具体细胞转移路径」，另加 rationale（为临床试验提供基础）。**hypothesis 说明目标可行性，rationale 说明目标重要性与对长远目标的贡献**，两者齐备目标才坚实可靠。
