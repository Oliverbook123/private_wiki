# 相关技术理论、数据集与评价指标

学位论文第 2 章「相关技术及理论」的目的：阐述研究涉及的背景技术、基础理论与相关算法，为研究方法与实验打基础；需要公式和图。该章**最容易出字数，但查重率最高**——初稿先填内容，结构完成后再降重。^[raw/bilibili/SubBatch_2026-09-30-14-37-34_MD/【炮哥带你学】—炮哥带你一周搞定人工智能算法论文（手把手论文撰写教学） - P6【6、相关技术及理论】—【2025-03-06】-中文.md]

## 2.1 相关物理背景
- 按研究方向补充工科/领域背景（医学、电力、气象等）；背景简单的方向（如安全帽检测）可省略。
- 素材参考前人论文揉合，多画图、多写公式。

## 2.2 基础理论（按任务选）
- **万金油**：激活函数、损失函数、反向传播——只要写神经网络就绕不开。
- 按任务选网络：视觉→CNN（卷积/池化）；时序/预测→RNN/LSTM；其他场景→GAN、自注意力/Transformer。
- 只写**底层小模块**：不要在此章把 YOLOv8 这类主模型整体写进去（那是第 3 章的事，见 [[thesis-model-chapter]]）。
- 合规：公式一般不查重，但理论措辞要降重；UP 主的图带水印，必须自己重画。

## 2.3 公开数据集
- 按任务列经典公开数据集（图像分类：手写数字识别等；检测：COCO、VOC；NLP 等）；交叉学科若有公开数据集也可列出介绍（哪怕最终不用，先充数）。
- 只列与本人任务相关的，不要无脑照搬模板里的检测数据集。

## 2.4 评价指标
| 任务类型 | 常用指标 |
|---|---|
| 分类 | 准确率、精确率、召回率、F1 |
| 回归/预测 | RMSE、MAE、MSE、R² |
| 目标检测 | 准确率/精确率/召回率/F1 + mAP、IoU |

- 目标检测本质是分类（是什么）+ 回归（框在哪）的综合，故兼有两类指标。
- **按任务选指标**：做回归就写回归指标，做分类就写分类指标，「不伦不类」最忌讳；指标也可放到实验章写。
- 评价指标是实验章结果表格与消融/对比的口径基础，见 [[experiment-design-and-analysis]]。
