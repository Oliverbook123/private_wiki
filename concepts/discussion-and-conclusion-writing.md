# 结果、讨论与结论的写作

按 [[paper-three-segment-structure]] 的三段式框架，结果部分按说明文写，讨论与结论按议论文写；个别论文可把 Results 与 Discussion 合并，但多数分开——使论文中**事实与观点的区分更清晰**。^[raw/bilibili/SubBatch_2026-09-30-10-16-54_MD/【SCI论文写作】—【全20集】目前B站最完整的论文写作教程，包含所有干货内容！这还没人看，我不更了！ - P18【18结果,讨论和结论的写作要点】—【2024-04-03】-中文.md]

## Results：客观事实
- 只客观描述自己的研究结果、给出基于数据的事实，**不附加任何个人观点**；重检验客观，少用转折，尽量用简单句型。
- 需分门别类、分层次、分段写时务必分类清晰、层次分明；突出关键数据、有科学意义与有代表性的数据；各类结果之间保持适当均衡。
- 做到**两个一致**：
  1. 结果内容与研究方法一致——每条结果都有对应的方法，内容最好具可复制性（他人用同样方法也能得到同样结果）；
  2. 文字与图表一致——文字不简单重复图表，而应高度概括，指出图表体现的关键特性或趋势（文字提供总结，图表提供细节支持）。
- 结果部分只描述、不作解释或比较；对结果的解释放讨论。

## Discussion：选择性深入分析
- 议论文写法，重在逻辑（归纳/演绎/溯因，见 [[literature-analysis-logic]]）；**不重复描述所有结果**，而是选择性深入分析关键结果、得出有意义推论。
- 引用自己的结果与引用文献性质相同：自己的结果与文献中的结果、结论都是推理可用的论据。

### 三种比较（P18）
1. 结果与**预期目标**比较：按研究目标比对实际与预期；不符时尽量给解释，并按实际结果指出本次研究的局限；
2. 结果与**相关文献**比较：最好能指出本次研究的创新点、优势或特色；
3. 结果与**长远目标**比较：说明本次研究对长远目标的实际贡献、理论意义、实用价值或推广前景。

### 逻辑架构（P19）
- 分段依据**论点**而非结果（结果部分的分段则与研究方法一一对应），按论点重要程度排序，先写重要的。
- 论证三要素：**结论/主张 — 理由 — 证据**。理由是逻辑理由，抽象、经自己思考得出，不需标注出处；证据客观、来自自己的研究之外，必须记录并引用出处（除非证据即本次研究结果）。
- 常用组段方式：一个段落论述一条理由，主题句即该理由的一句话总结，段落主体为支持它的证据集合；三个理由用三段，最后一段总结论。多条结论则用多组段落，可加小标题；也可一段论证一条结论（主题句=结论总结），段落脉络或**归纳**（罗列结果/文献证据后归纳出结论）或**演绎**（先提出文献理论，再结合本次结果推出结论）。
- 段落之间的逻辑关联（递进、因果、转折，最弱为并列）用段头段尾连接词表达（in addition / furthermore，as a result，however / on the other hand），最终都指向结论。
- 从研究结果出发往前推两步甚至三步，直到得出有意义的结论；构思分两步走：先头脑风暴得出初步结论，再回头寻找证据完善理由，最后调整结论。

### 四个写作方向（P20）
| 方向 | 回答的问题 | 内容 | 常用表达 |
|---|---|---|---|
| 解释 interpretations | 结果说明什么（why，往前推找原因） | 从符合预期的结果提取规律性知识；对意外结果做各种可能原因的解读 | indicate / show / suggest / confirm；与文献比用 consistent / agree / differ / unlike |
| 延伸 implications | 结果为何重要（so what，往后推找后果） | 指出创新性与重要性；给出具体贡献、意义、影响 | innovation / new / first time；provide / support / be useful |
| 局限 limitations | 结果不能告诉我们什么 | 研究目标、方法或结果本身的合理局限 | however（慎用） |
| 建议 recommendations | 后续应有什么行动或研究 | 结合长期目标谈尚存距离与下一步 | further / additional / next step |

- 解释与延伸是对结果的**主体拓展**；局限与建议是**侧向补强**（局限→建议之间也可能有因果递进）。
- 语气要适度：越具体越可信，善用 would / could / might / likely / probably 表达不同级别信心，切忌宽泛浮夸。
- 写局限的目的是**增强可信度**而非强调缺陷，只写合理、能被读者理解和原谅的局限；建议要与自己的研究有关联且有可行性，过于宽泛随意反损专业性，不如不写。

## Conclusion：亮点与方向缺一不可
- 结论一般可视为对讨论部分的总结；当研究目标或研究方法本身构成重要创新点时，结论中也应复述并强调其创新性。
- 好的结论做到两点：**突出亮点**（创新点，可来自结果的结论，也可来自目标或方法的创新）+ **指出局限与尚未解决的问题**，并对今后研究方向提出建议或设想。
