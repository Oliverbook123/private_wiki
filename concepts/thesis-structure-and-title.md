# 学位论文的章节结构与题目设计

人工智能/计算机/工科论文的章节结构「大差不差」，只是研究内容与方法不同；按模板填内容即可成稿。^[raw/bilibili/SubBatch_2026-09-30-14-37-34_MD/【炮哥带你学】—炮哥带你一周搞定人工智能算法论文（手把手论文撰写教学） - P2【2、论文整体结构的分析】—【2025-03-06】-中文.md, raw/bilibili/SubBatch_2026-09-30-14-37-34_MD/【炮哥带你学】—炮哥带你一周搞定人工智能算法论文（手把手论文撰写教学） - P13【13、研究内容及章节安排】—【2025-03-06】-中文.md]

## 章节结构（UP 主模板）
| 位置 | 内容 |
|---|---|
| 题目 | 定方向；见下 |
| 第 1 章 引言 | 研究背景及其意义、国内外研究现状、本文研究内容及章节安排 |
| 第 2 章 相关原理 | 相关技术及理论、数据集、评价指标 |
| 第 3 章 模型解析 | 所用算法在目标场景的应用与（如有）改进 |
| 第 4 章 实验设计与结果分析 | 实验环境、数据处理、实验过程与结果、消融/对比实验、（可选）系统设计与实现 |
| 第 5 章 总结与展望 | 总结贡献 + 不足与未来方向 |
| 摘要 | 版式靠前但**必须最后写**（见 [[thesis-conclusion-and-abstract]]） |

- 第 1.3 节「研究内容及章节安排」同样最后写：论文没写完，结构不清晰，写不了。章节安排即把各章用一两句话概括。^[raw/bilibili/SubBatch_2026-09-30-14-37-34_MD/【炮哥带你学】—炮哥带你一周搞定人工智能算法论文（手把手论文撰写教学） - P13【13、研究内容及章节安排】—【2025-03-06】-中文.md]
- 第 3 章内容少时可与第 4 章合并；有算法改进时硕士论文应单独成章详述改进（详见 [[thesis-model-chapter]]）。^[raw/bilibili/SubBatch_2026-09-30-14-37-34_MD/【炮哥带你学】—炮哥带你一周搞定人工智能算法论文（手把手论文撰写教学） - P7【7、基于某种算法的某某场景模型解析】—【2025-03-06】-中文.md]
- 表中第 4 章「（可选）系统设计与实现」出自 P11（本科建议有，详见 [[thesis-model-chapter]]）。^[raw/bilibili/SubBatch_2026-09-30-14-37-34_MD/【炮哥带你学】—炮哥带你一周搞定人工智能算法论文（手把手论文撰写教学） - P11【11、模型系统的设计】—【2025-03-06】-中文.md]
- 本科/硕士差异：本科可不做对比/消融实验；硕士必须有改进 + 消融 + 对比。图表越多、实验越详，工作量显得越大，但第 4 章是核心不能水。^[raw/bilibili/SubBatch_2026-09-30-14-37-34_MD/【炮哥带你学】—炮哥带你一周搞定人工智能算法论文（手把手论文撰写教学） - P2【2、论文整体结构的分析】—【2025-03-06】-中文.md]

## 题目设计（P3）
两类基本题型：
1. **算法研究类**：「某某算法的研究」「基于某某算法在某场景下的研究/改进」——突出算法本身的工作与改进；有改进必须配对比实验和消融实验证明有效性；硕士题目应体现改进内容。
2. **系统设计与实现类**：「基于某某算法在某场景下的系统设计与实现」——算法 + 简单界面调用展示，偏工程实现，本科常用（算法+系统=工作量）；硕士做系统则须更「高大上」，否则显得与本科无异。

- 也有结合式：「……的研究与系统设计与实现」；本科用「基于某算法的某场景研究与系统实现」即可，硕士建议砍掉系统、聚焦算法改进。
- 要领：题目规整、不庸俗不夸张；**聚焦一个方向**（做得太宽泛不好写）。

## 合规边界
UP 主反复强调：模板带水印、**不要抄**，参考揉合后必须降重；公式一般不查重但图要自己画。详见 [[predatory-journal-market]] 的学术不端风险与本校 [[cs-course-credits]] 的科研伦理必修课。
