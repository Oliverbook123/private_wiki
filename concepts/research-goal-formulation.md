## goal 与 objective：大处着眼，小处着手
八字方针「大处着眼、小处着手」看似矛盾，统一的关键在于有能力把手头的小事与心中的大事联系起来：

| | goal（长远目标） | objective（当前目标） |
|---|---|---|
| 比喻 | 宏伟的建筑 / 终点站 | 一砖一瓦 / 里程碑 |
| 归属 | 常与许多研究者共享，全世界共同推进 | 通常为己独有，为小的切入点 |
| 来源 | 真实市场需求、本领域专家建议、主要科研基金机构的服务宗旨 | 根据自身现有资源条件制定 |

只盯眼前小事会流于苟且无意义；只谈心中大事会陷于大而空。引言的重要作用正是把 objective 与 goal 联系起来（见 [[introduction-writing]]）。

## 确立研究课题的三种途径
1. **填补研究空白**：发现现有文献的空白或者漏洞并提出课题弥补。空白多为 old problem——重要性已被公认，但技术上仍具挑战。要点：**强调课题中的创新部分**（新方案或跨领域借鉴的新想法），并论述与前人尝试的不同与互补。
2. **延伸现有研究**：追踪领域研究历史，一项接一项累积递进，常涉及 new problem 甚至新领域，孕育机会更多但意义不明确、易迷失。要点：始终**牢记长期目标**，审视工作对长期目标与目标受众的实际贡献。
3. **复制成功研究**：把一项成功研究在不同变量范围、样本群甚至领域中复制，相对安全普遍。要点：**注意原研究的前提和假设**，以及本地条件可能带来的差异，避免复制错误。

三种途径可单独或组合使用。教程认为最突出的两类课题是：完善知识框架后无人可再改进（途径一极致），或突破知识框架为后来者打开大门（途径二极致）。

## 好课题的三条准则
1. **具体可行**：术语和变量均有明确定义、课题有明确边界、无先入为主的假设、适合现有资源条件。
2. **开放可争议**：可证伪性是区分科学与非科学的标准，不可证伪的课题不科学。
3. **能激发创新**：为创新制造机会，跨领域、跨学科思考往往是创新来源。

## 结构化分解：把大问题拆小（P12）
有洞察力的人一眼抓住事物的核心矛盾；有创造力的人更进一步把核心矛盾转化为更易解决的矛盾：
1. 对矛盾的各个核心要素分别用结构化思维向下分解为多层小金字塔（分解时同样适用 MECE 法则，见 [[structured-thinking-pyramid]]）；
2. 分解中可能发现新的核心要素，使原有矛盾（A×B）转化为新要素间的矛盾（A1×B1）；
3. 对关键要素量化、对关键问题公式化，把笼统问题转化为几个关键变量间的关系问题；
4. 对关键变量提出假设、按假设收集数据、验证并更新假设，筛出最有意义的研究目标。

示例（教程原例「把 2L 的水放入 1L 的杯子」）：分解为杯子（→如何做弹性杯）、水（→冻成何种形状）、重力环境（→到太空失重）三个要素，各自得出不同解法再择优。「我们遇到的大多数问题，都源于我们没有准确地定义这些问题」。

## 文献检索细化（P13）
文献资料丰富程度对目标应有的细化程度有实际参考意义：
1. **概念化**：提炼研究目标涉及的所有关键概念，借助课本与综述了解各概念的内涵外延；
2. **多表达检索**：同一关键概念往往有多种同义词、近义词与不同表达，检索时要尽量覆盖——先用 OR 分别取概念 A、概念 B 的文献集合，再用 AND 求交集。教程示例：研究「屏幕上的暴力对儿童的影响」时，屏幕（movie/TV/DVD…）、暴力（violence/aggression/crime…）、儿童（children/teenager/youth…）各成同义词组；
3. **评估搜索结果**：识别 key players（重要的 key researchers 与 key journals），了解其研究、方法与通行术语，供精细化定义目标参考；
4. **数量校准**：文献过于庞大说明目标可能过宽，应结合文献可提供的资源支持力度评估自身资源，进一步细化目标；
5. **分类细化**：按研究方法、地理位置、流程阶段等维度给文献分类，发掘目标可分解的各个方面，使细化后的目标与现有文献更契合、更互补。

「检索—评估—细化」流程通常需多次循环，其泛读性质见 [[literature-reading-method]]。
