# 引言的逻辑解析与写作模板

引言应按一篇完整的议论文来写，其中心论点是「本篇论文**研究目标的合理性**」。教程给出一个把引言与研究目标描述作为整体考虑的两段式模板。^[raw/bilibili/SubBatch_2026-09-30-10-16-54_MD/【SCI论文写作】—【全20集】目前B站最完整的论文写作教程，包含所有干货内容！这还没人看，我不更了！ - P2【2引言的逻辑解析】—【2024-04-03】-中文.md]

## 两段式模板
| 段落 | 功能 | 走向 |
|---|---|---|
| 第一段 | 确立研究机会 | 从普遍的大问题（problem）到具体的研究问题（question） |
| 第二段 | 提出解决方案 | 清晰描述研究目标，填补第一段确立的研究空白、占领研究机会 |

- **problem 与 question**：中文均可译作「问题」，但 problem 更具挑战意味、与 solution 相对应；question 与具体的 answer 相对应。
- **goal 与 objective**：goal 指长期目标，objective 指当前（本论文）目标。第二段的目标描述往往不仅包括本论文目标，也包括作者的长期目标。

## 两段之间的呼应关系
| 引言 | 对应 |
|---|---|
| 第一段的普遍大问题 problem | 长期目标 goal |
| 第一段确立的具体研究问题 question | 当前论文目标 objective |

- 第一段论证：为了解决某个普遍的大问题，**需要回答**某个具体的研究问题。
- 第二段论证：为了实现长期目标，**首先需要实现**本论文的特定目标。
- 该对应关系不是绝对的，但掌握它有助于加深对文章逻辑关系的理解。

## 开头：从读者已知到未知
引言好比搭一座桥，要引导读者从他们现有的位置过桥进入我们的世界；桥的起点（引言开头）必须和读者现有的知识框架建立联系：
1. 提出读者当下关切的问题，从读者已经认同的观念（读者已知的）入手；
2. 逐步加入读者可能未知的文献资料，并以这些文献作为理由；
3. 说服读者：有一个具体的研究问题值得研究、读者应该知道它的答案——这个研究问题即对应本论文的研究目标。

### 第一段论述模式示例
> 问题 X 的重要性已被学术界广泛认可。研究者 A 发现了……研究者 B 发现了……基于这些理由，我们认为回答问题 C 对于解决问题 X 至关重要。

## 写作时机
引言一般落脚于研究目标，很多论文在引言结尾处连接对研究目标的完整描述；写引言不需要实验数据，宜尽早动笔（出自 P1，见 [[paper-three-segment-structure]]）。目标如何定义、与长期目标如何呼应，见 [[research-goal-description]]。
