# 期刊与会议的级别划分

## 查询渠道
- 中文期刊：知网（字幕「支网」）期刊导航
- 外文期刊：LetPub（字幕 let's pop）；小木虫（字幕「小牧虫」）为国人仿 LetPub 的站点，UP 主认为其内容与 LetPub 有差距
- 计算机领域：CCF（中国计算机学会）发布推荐国际学术期刊/会议目录（分两份 PDF），期刊与会议各分 A/B/C 三类——顶会认定见 [[top-journal-conference]]

## 维度一：刊号（CN / ISSN）
- CN 为国内刊号、ISSN 为国际刊号，相当于期刊的「身份证号」
- ISSN 在国外较易申请，CN 在国内难申请；国内刊物一般同时持有两种
- **国内一般只认 CN 刊号**：有 CN 即可视为正规刊物，有无 ISSN 并不重要；SCI 收录刊物不以此论（原视频补充：「SCI 的话那这个就定论了」）
- 风险：近年有不法分子在境外注册仅持 ISSN 的刊物实施诈骗，需警惕，见 [[predatory-journal-market]]

## 维度二：地域（国家级 / 省级）
- **无明确划分标准**，习惯上按期刊主管/主办单位层级认定（如教育部主办→国家级，省社科院主办→省级）
- 学校一般不会按刊号所属地或地域划分来规定毕业论文/成果的期刊要求

## 维度三：核心期刊与索引收录

### 国内核心（「七大核心」，常用的 4 种）
| 核心 | 特点 |
|---|---|
| 北大核心 | 普及最广、应用范围最广；综合性，文理均有 |
| 南大核心（CSSCI） | 最权威；通行上偏人文社科（本视频未展开，属常识补充） |
| 科技核心（中国科技核心） | 医药类机构采用较多 |
| CSCD | 理科采用较多 |

- 另有人文社科方向的核心（字幕列举不全、转录不清，七大核心名录以官方版本为准）
- **不同学校认同的核心不同**：A 校认北大核心、B 校认南大核心，互投可能不被认可——投递前必须核对学校文件，乱投的后果由自己承担
- 投刊策略（UP 主观点）：不必死记核心名录与优劣，往领域内最好的核心期刊投（如自动化学报、计算机学报、计算机研究与发展；字幕后文「分为两种三大气概……和其他」一句转录混乱，疑指「三大刊物：计算机学报、软件学报、计算机研究与发展」，转录存疑，且此名单与前文「三大学报」不完全一致）；不打算读博就跟随实验室师兄姐验证过的投刊方向

### 国际核心（四种索引）
- **SCI**（理工科）、**SSCI**（社会科学）、**AHCI**（艺术类）、**EI**（工程类）；理工科主要看 SCI 与 EI
- SCI 是索引库：库内期刊按 JCR 划分 Q1–Q4（近似平均四等分）；**国内一般认可中科院分区**（按固定比例的档位划分）
- SSCI / AHCI / EI 的区划需另行检索，本页不展开

### 国际会议（ISTP / EI）
- 国际会议核心主要为 ISTP 与 EI，以理工/科技类为主
- 计算机领域格外看重会议（CCF 会议目录）；其他领域会议含金量普遍偏低
- **多数学校不认可会议论文**；EI 会议一度被认为「给钱就行」，部分学校 EI 会议可与核心期刊等同（见 [[predatory-journal-market]]）

## CCF 与 SCI 的区别
- CCF（A/B/C）是计算机领域权威专家的评级；SCI 按期刊影响因子划分、覆盖学科更广
- 多数学校国际期刊以 SCI 为准，部分学校以 CCF 为准；国内期刊分级（T1/T2/T3）在学校文件中通常被映射为校内 A/B/C 类（见 [[top-journal-conference]]）
