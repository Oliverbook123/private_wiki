# 计算机类学科研究方向一览（2026 级）

^[raw/papers/peiyang-fangan-2026.extracted.txt]

## 计算机科学与技术（0812）
| # | 方向 | 关键词 |
|---|---|---|
| 1 | 机器学习与人工智能 | 深度学习高效算法、可解释性、粒计算、粗糙集 |
| 2 | 智能计算与优化理论 | 跨模态感知、类脑计算、演化计算、医学影像 |
| 3 | 嵌入式系统与体系结构 | SoC、软硬件协同、RTOS、边缘计算、无人机 |
| 4 | 智慧海洋与船舶信息处理 | 宽带通信、自组织网络、声纳定位、船海大模型 |
| 5 | 大数据挖掘与信息系统 | 存储索引、云计算、知识图谱、关联分析 |
| 6 | 可信计算与信息安全 | 可信计算、密码学、区块链、隐私计算 |

## 软件工程（0835）
| # | 方向 | 关键词 |
|---|---|---|
| 1 | 智能信息处理与系统建模 | 机器学习、进化计算、多模态知识发现 |
| 2 | 语义网与 Web 技术 | 本体建模、知识图谱、语义推理、Web 3.0 搜索推荐 |
| 3 | 网络与信息安全 | 密码学、入侵检测、云/物联网安全、漏洞挖掘 |
| 4 | 嵌入式系统及应用 | Co-design、低功耗、工业互联网、智能感知 |
| 5 | 项目管理与信息系统 | 信息系统治理、商业智能、知识管理 |

## 人工智能（99J3）
| # | 方向 | 关键词 |
|---|---|---|
| 1 | 图像处理与计算机视觉 | 目标检测/跟踪/分割、工业视觉、医学影像 |
| 2 | 模式识别与机器学习 | PAC 可学习性、GNN、深度学习模型演进 |
| 3 | 自然语言处理 | 语言建模、机器翻译、知识图谱、NER、对话系统 |
| 4 | 智能计算与优化理论 | 类脑计算、认知学习、群体智能（与 0812-2 同） |
| 5 | 知识发现与数据挖掘 | 粒计算、时序/空间大数据、可视化 |
| 6 | 智慧海洋与船舶信息处理 | 船海大模型、多目标探测（与 0812-4 同） |

## 观察
- 人工智能学科（99J3）与 0812 共享 2 个方向，方向 1-3 更贴近当下 LLM/CV 热点
- "语义网与 Web 技术"是 0835 独有；"自然语言处理"是 99J3 独有（0812/0835 无 NLP 方向，仅有同名课程）
- 全部学科的船海特色集中在"智慧海洋与船舶信息处理"
